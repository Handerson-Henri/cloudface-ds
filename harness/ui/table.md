# Table

## Propósito
Dados tabulares. EmptyState no tbody quando não há linhas.

## API
`Table`, `TableHead`, `TableBody`, `TableRow`, `TableCell` (`header` para th), `TableCaption`.

## Variantes e tamanhos
Único visual nesta leva.

## Estados
default; empty via EmptyState.

## Tokens usados
`color.fg.*`, `color.border.default`.

## Exemplos
Storybook Estrutura/Table.

## Teclado
Nativo da tabela.

## Acessibilidade
`th` via `header`. Caption opcional.
