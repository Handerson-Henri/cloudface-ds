# Popover

## Propósito
Painel ancorado abaixo do trigger. Sem Floating UI.

## API
`open`, `onClose`, `trigger`, `children`.

## Teclado
| Tecla | Ação |
|---|---|
| Esc | Fecha |
| Tab | Cicla no painel |

## Acessibilidade
`role="dialog"`. Trap compartilhado. Clique no trigger abre/fecha.
