# Switch

## Propósito
Liga/desliga. `role="switch"` no input nativo escondido.

## Estados
default, checked (ciano), focus-visible no track, disabled (borda + fg disabled).

## Teclado
Espaço/Enter no input. Foco visível no track.

## Acessibilidade
Label envolve o controle. Track com borda `border.control` para contrastar no canvas.
