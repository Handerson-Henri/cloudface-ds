# CheckboxGroup

## Propósito
Grupo de checkboxes com legend visível.

## Anatomia
container e conteúdo visível.

## API
| Prop | Tipo | Padrão | Descrição |
|---|---|---|---|
| legend | string | — | fieldset legend |
| error | string | — | Erro com texto e ícone |

## Variantes e tamanhos
Único layout.

## Estados
default, invalid.

## Tokens usados
`color.bg.*`, `color.fg.*`, `color.border.*`, `color.action.primary.*`, `color.feedback.*`, `color.focus.ring`.

## Exemplos
Storybook: pasta do componente. Docs Vite: nav correspondente.

## Teclado
HTML nativo ou ARIA APG. Esc fecha overlay.

## Acessibilidade
fieldset/legend (1.3.1).
