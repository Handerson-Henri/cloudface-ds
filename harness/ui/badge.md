# Badge

## Propósito
Status curto. Status leva ícone (1.4.1).

## API
| Prop | Tipo | Padrão | Descrição |
|---|---|---|---|
| variant | default/info/success/warning/error | default | Tom |
| size | sm/md | md | Altura |
| icon | boolean | true se não default | Ícone de status |

## Variantes e tamanhos
Menta só em success.
