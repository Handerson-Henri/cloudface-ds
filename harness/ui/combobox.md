# Combobox

## Propósito
Lista buscável (APG). Select nativo continua para listas curtas estáticas.

## Teclado
| Tecla | Ação |
|---|---|
| Seta baixo/cima | Abre e move o highlight |
| Enter | Confirma o highlight |
| Esc | Fecha |

`aria-selected` marca o **valor commitado**, não o highlight (`aria-activedescendant`). Lista vazia: “Nenhum resultado”.
