# Cloudface — ID visual

Pacote de ativos para apresentações, site, redes sociais e produção física.

## Direção visual

- **Personalidade:** infraestrutura de rede, precisão técnica e movimento contínuo.
- **Base:** azul-marinho quase preto e superfícies grafite.
- **Acentos:** ciano elétrico para sinal/conexão e verde menta para estados positivos.
- **Tipografia digital:** Sora para títulos e Manrope para textos/interface.
- **Tipografia de conteúdo:** DM Sans e Barlow Condensed Bold.

## Arquivos

- `logos/`: wordmarks e símbolo em versões claras/escuras.
- `fonts/`: fontes usadas nos materiais e no site.
- `referencias/`: referências visuais de direção de arte.
- `movimento/`: variações SVG do sistema Möbius para motion.
- `produção-pvc/`: arquivos prontos para o painel PVC de 150 × 50 cm.
